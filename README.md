## État du projet

Ce projet n'est pas abouti. Je travaille actuellement sur d'autres projets, il est donc en pause.
En l'état, il contient les fonctionnalités de base, elles-mêmes limitées au minimum de ce qu'elles doivent fournir.

## Perspectives

Dans un futur plus ou moins proche, j'aimerais :

- ajouter des fonctionnalités ;
- approfondir celles déjà présentes ;
- changer le format de sortie afin que la commande s'intègre proprement dans des scripts ;
- apporter ma touche, pour que l'utilitaire ait une raison d'être utilisé plutôt qu'un autre ;
- explorer ce qui est peu ou mal fait dans les utilitaires existants, et y apporter une solution.
